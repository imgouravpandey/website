EKS upgrades across multiple Kubernetes versions are complex, especially in production environments with custom networking, service meshes, and stateful workloads. Built comprehensive upgrade tooling and documentation that was used across multiple customer engagements.

**What I built:**
- Step-by-step upgrade scripts with pre-flight checks
- Rollback procedures for each upgrade stage
- Documentation covering add-on compatibility, API deprecations, and breaking changes
- Deep dives into Kubernetes 1.34 and 1.35 feature changes

**Tools:** EKS, Kubernetes, Bash, Terraform
